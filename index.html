How it works

Three steps to start

  1. 01

    Run start.bat

    Download ONYX, unpack the archive and run start.bat. Wait until it finishes loading.

  2. 02

    Join the game

    Launch RobRun and join a match as usual, ONYX is already running in the background

  3. 03

    Press Insert

    Press Insert in-game to open the cheat menu. Press it again to hide it.
